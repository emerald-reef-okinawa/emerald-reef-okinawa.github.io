FAQ

よくある質問

ご参加前にご確認ください。他にご不明点があればお気軽にお問い合わせを。

Q何名から参加できますか？
+
お一人様からご家族・グループまで対応しています。スキンダイビングは1名様からもご参加いただけます（1名 ¥12,000）。ご人数に合わせたプランをご提案しますので、お気軽にお問い合わせください。
Q子供は何歳から参加できますか？
+
シュノーケルは3歳以上からご参加いただけます（保護者同伴必須。幼児3〜5歳は大人1名につき1名無料）。スキンダイビングは小学生以上を目安としています。お子様の年齢・体力に合わせて安全に楽しめるよう配慮しますので、ご予約時にご相談ください。
Q荒天・雨天の場合はどうなりますか？
+
台風や強風など海況が悪い場合は安全のため中止となる場合があります。小雨程度であれば実施可能なことが多いです。中止の際はまず日程の振替をご提案し、振替が難しい場合は全額返金にて対応いたします。前日までにご連絡します。
Q持ち物は何が必要ですか？
+
水着・タオルをご用意ください。その他の機材（マスク・フィン・ライフジャケットなど）はすべてご用意しています。
Q英語での対応はできますか？
+
はい、英語での対応が可能です。海外からのお客様も多くいらっしゃいます。予約・当日の説明・サポートすべて英語でお受けできます。
Q送迎はどこまでしてもらえますか？
+
沖縄本島内のホテル・宿泊施設・ご指定の場所への送迎に対応しています。那覇市内から恩納村エリアまで幅広く対応していますので、ご予約時にご宿泊場所をお知らせください。
Qキャンセルポリシーを教えてください。
+
7日前まで：無料。6日前〜前日18時まで：料金の50%。前日18時以降・当日・無連絡：料金の100%をキャンセル料として申し受けます。天候・海況による中止の場合は、まず日程の振替をご提案し、難しい場合は全額返金いたします。
Q当日・前日でも予約できますか？
+
はい、空きがあれば当日・前日のご予約も大歓迎です。急なご旅行や思い立ったときはお気軽にお問い合わせください。迅速に対応いたします。
Q海が怖い・初めてでも大丈夫ですか？
+
海が怖い方・初めての方も大歓迎です！ライフジャケットを着ているので、顔を水につけるだけで自然に浮くことができます。水中に潜らなくても色鮮やかな熱帯魚やサンゴを間近で見られます。ガイドが常にそばについていますので、ご自身のペースで無理なく楽しんでいただけます。
Q妊娠中・持病がある場合は参加できますか？
+
妊娠中の方・心臓疾患・てんかん・喘息などの持病がある方は、事前に必ず主治医にご相談のうえご参加ください。ご予約時にお知らせいただければ、適切なサポートをご提供できます。安全を最優先に対応いたします。
Q写真・動画はいつ、どうやって受け取れますか？
+
体験後24〜48時間以内に、ご登録のメールアドレスへダウンロードリンクをお送りします。撮影写真は無料、動画データも今だけ無料でプレゼント中です。インターネット環境があれば海外でも受け取れます。
Q支払い方法を教えてください。
+
現金またはクレジットカード（Visa・Mastercard・JCB・Amex）でのお支払いが可能です。当日ガイドに直接お支払いください。事前のお振込は不要です。
Q日焼け止めはどうすればいいですか？
+
サンゴ礁保護のため、オーシャンフレンドリー（reef-safe）な日焼け止めのご使用をお願いしています。化学成分（オキシベンゾン等）を含む一般的な日焼け止めはサンゴに悪影響を与える場合があります。ミネラル系（酸化亜鉛・酸化チタン配合）をお選びください。当日ご不明な場合はスタッフにご相談ください。
